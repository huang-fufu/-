# Step 2: 生成项目大纲

在素材导入完成后，触发 ReanimAI 的 AI 引擎生成项目大纲，包括故事主题、核心冲突、主要角色等。

## 前置条件

- Step 1（导入素材）已完成
- 页面已显示素材导入成功的状态

## 操作步骤

### 1. 触发大纲生成

```
1. 在创作流程页面，找到"生成项目大纲"按钮或自动触发区域
2. 点击"生成大纲"或等待系统自动开始
3. 截图确认生成过程已启动
```

### 2. 等待生成完成

```
1. 观察页面状态变化（加载中/生成中/已完成）
2. 等待 AI 生成完成（通常需要 10-30 秒）
3. 截图确认大纲已生成
```

### 3. 展示并确认

```
1. 截图展示生成的大纲内容给用户
2. 询问用户是否满意，是否需要修改
3. 如果用户要求修改，根据反馈调整创意描述后重新生成
4. 用户确认后，点击"下一步"进入结构细纲
```

## 大纲通常包含的内容

- 故事主题/类型
- 核心冲突
- 主要角色简介
- 故事背景设定
- 整体叙事方向

## 注意事项

- 生成过程中不要重复点击，避免触发多次生成
- 如果生成失败，截图反馈，尝试重新触发
- 大纲不满意可以回到 Step 1 修改素材后重新生成
