# Step 5: 故事结构审核

在分幕场次生成后，触发 AI 对整体故事结构进行专业审核，检查逻辑性、节奏、冲突等。

## 前置条件

- Step 4（生成分幕场次）已完成且用户已确认

## 操作步骤

### 1. 触发故事审核

```
1. 在创作流程页面，找到"故事结构审核"按钮
2. 点击触发审核
3. 截图确认审核过程已启动
```

### 2. 等待审核完成

```
1. 观察页面状态变化
2. 等待 AI 审核完成（通常需要 15-40 秒）
3. 截图确认审核结果已生成
```

### 3. 展示审核结果

```
1. 截图展示审核结果给用户
2. 审核结果通常包含：
   - 故事逻辑性评估
   - 节奏把控分析
   - 冲突设置评价
   - 角色发展建议
   - 需要修改的问题点
3. 如果有问题，询问用户是否要修改
```

### 4. 处理审核反馈

**情况A：审核通过**
```
1. 用户确认无问题
2. 点击"下一步"进入正式剧本生成
```

**情况B：需要修改**
```
1. 根据审核建议，回到对应步骤修改
2. 重新生成后再次审核
3. 直到审核通过
```

## 注意事项

- 审核是质量把关环节，认真对待审核结果
- 如果审核指出严重问题，建议修改后再继续
- 用户可以跳过审核直接生成剧本（不推荐）
