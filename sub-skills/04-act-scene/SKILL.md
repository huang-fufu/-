# Step 4: 生成分幕场次

在结构细纲确认后，触发 AI 将细纲细化为具体的幕和场次划分。

## 前置条件

- Step 3（生成结构细纲）已完成且用户已确认

## 操作步骤

### 1. 触发分幕场次生成

```
1. 在创作流程页面，找到"生成分幕场次"按钮
2. 点击触发分幕场次生成
3. 截图确认生成过程已启动
```

### 2. 等待生成完成

```
1. 观察页面状态变化
2. 等待 AI 生成完成（通常需要 20-60 秒）
3. 截图确认分幕场次已生成
```

### 3. 展示并确认

```
1. 截图展示生成的分幕场次内容给用户
2. 分幕场次通常包含：
   - 第一幕/第二幕/第三幕的划分
   - 每幕包含的具体场次
   - 每场的场景描述
   - 每场的核心事件/冲突
   - 场次之间的情感节奏
3. 询问用户是否满意
4. 用户确认后，点击"下一步"进入故事结构审核
```

## 注意事项

- 分幕场次是最详细的情节规划，生成时间较长
- 如果用户对某幕/某场不满意，可以要求调整
- 确认分幕场次后再进入审核，避免返工
