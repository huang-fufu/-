# Step 6: 生成正式剧本

在故事结构审核通过后，触发 AI 生成完整的正式剧本文本。

## 前置条件

- Step 5（故事结构审核）已完成且审核通过

## 操作步骤

### 1. 触发剧本生成

```
1. 在创作流程页面，找到"生成正式剧本"按钮
2. 点击触发剧本生成
3. 截图确认生成过程已启动
```

### 2. 等待生成完成

```
1. 观察页面状态变化
2. 等待 AI 生成完成（通常需要 30-90 秒，这是最耗时的一步）
3. 截图确认剧本已生成
```

### 3. 展示剧本内容

```
1. 截图展示生成的剧本内容给用户
2. 剧本通常包含：
   - 场景描述（时间、地点、氛围）
   - 角色对话
   - 动作指示
   - 情感提示
   - 镜头建议（部分平台支持）
3. 询问用户是否满意
```

### 4. 处理用户反馈

**情况A：满意**
```
1. 用户确认剧本 OK
2. 点击"下一步"进入下载
```

**情况B：需要修改**
```
1. 根据用户反馈，回到对应步骤修改
2. 重新生成剧本
3. 直到用户满意
```

## 注意事项

- 剧本生成是最耗时的步骤，耐心等待
- 生成过程中不要切换页面或关闭浏览器
- 如果生成失败，截图反馈，尝试重新生成
- 剧本内容较长，可能需要滚动查看完整内容
