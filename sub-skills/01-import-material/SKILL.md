# Step 1: 导入素材/创意

在 ReanimAI 剧本创作页面中，上传素材文件或输入故事创意，作为后续剧本生成的基础。

## 前置条件

- 已登录 ReanimAI 账号
- 已进入 ReanimAI 的剧本创作/短剧创作模块
- 用户已准备好素材（故事创意、参考文本、角色设定等）

## 操作步骤

### 1. 进入剧本创作页面

```
1. 导航到 ReanimAI 的剧本创作入口
2. 点击"新建项目"或"创建剧本"
3. 选择创作类型（短剧/电影/其他）
4. 截图确认已进入创作页面
```

### 2. 导入素材

根据用户提供的素材类型，选择对应方式：

**方式A：输入文字创意**
```
1. 找到"输入创意"或"故事概述"文本框
2. 将用户的创意描述粘贴/输入进去
3. 截图确认内容已填入
```

**方式B：上传文件**
```
1. 找到"上传素材"或"导入文件"按钮
2. 点击上传按钮，选择用户提供的文件
3. 等待上传完成
4. 截图确认文件已上传
```

### 3. 确认并提交

```
1. 检查素材内容是否正确
2. 点击"确认"或"下一步"按钮
3. 截图确认进入下一步（生成项目大纲）
```

## 注意事项

- 如果页面有多个输入框，优先使用"创意描述"或"故事概述"字段
- 上传文件格式通常为 .txt / .docx / .md
- 提交后等待 AI 处理，截图确认状态变化
- 如果提交失败，截图反馈给用户
