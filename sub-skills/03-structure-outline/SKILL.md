# Step 3: 生成结构细纲

在项目大纲确认后，触发 AI 生成更详细的结构细纲，包括各章节/集数的内容规划。

## 前置条件

- Step 2（生成项目大纲）已完成且用户已确认

## 操作步骤

### 1. 触发细纲生成

```
1. 在创作流程页面，找到"生成结构细纲"按钮
2. 点击触发细纲生成
3. 截图确认生成过程已启动
```

### 2. 等待生成完成

```
1. 观察页面状态变化
2. 等待 AI 生成完成（通常需要 15-45 秒，比大纲生成更久）
3. 截图确认细纲已生成
```

### 3. 展示并确认

```
1. 截图展示生成的结构细纲内容给用户
2. 细纲通常包含：
   - 各集/各章的标题
   - 每集的核心事件
   - 角色发展线索
   - 情感节奏规划
3. 询问用户是否满意
4. 用户确认后，点击"下一步"进入分幕场次
```

## 注意事项

- 细纲比大纲更详细，生成时间更长，耐心等待
- 如果用户对某集/某章不满意，可以单独要求调整
- 避免在生成过程中切换页面
