# Step 7: 下载剧本

在正式剧本生成完成后，下载剧本文件到本地。

## 前置条件

- Step 6（生成正式剧本）已完成且用户已确认

## 操作步骤

### 1. 找到下载入口

```
1. 在创作流程页面，找到"下载剧本"按钮
2. 截图确认下载按钮可用
```

### 2. 执行下载

```
1. 点击"下载剧本"按钮
2. 如果有格式选择（.txt / .docx / .pdf），询问用户偏好
3. 等待下载完成
4. 截图确认下载状态
```

### 3. 确认下载结果

```
1. 检查浏览器下载栏，确认文件已下载
2. 告知用户文件保存位置
3. 截图展示下载完成的页面
```

### 4. 流程完成

```
1. 告知用户整个剧本创作流程已完成
2. 询问是否需要：
   - 在 ReanimAI 上继续进行资产设定/分镜制作
   - 修改剧本后重新生成
   - 创建新的剧本项目
```

## 注意事项

- 下载前确认剧本内容是最终版本
- 如果下载按钮不可用（灰色/禁用），截图反馈
- 下载完成后建议用户备份文件
- 整个 7 步流程到此完成
